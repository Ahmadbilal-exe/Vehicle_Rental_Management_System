# 🚗 Vehicle Rental Management System

A console-based **Vehicle Rental Management System** developed in C that allows administrators and customers to manage vehicle rentals, maintain customer records, track rental transactions, and generate bills efficiently.

This project was developed as a **1st Semester BS Computer Science project** at FAST NUCES.

## 🔐 Admin Authentication

**Default Admin Password:** `admin123`

## ✨ Features

### 👨‍💼 Admin Panel
- Secure administrator authentication
- Add single or multiple vehicles
- View all registered vehicles
- Update vehicle information
- Delete vehicles
- Check vehicle availability
- Search vehicles
- Search customers
- View customer records
- Monitor active rentals

### 👤 Customer Panel
- View available vehicles
- Search for vehicles
- Rent vehicles
- Return rented vehicles
- Generate rental bills
- Track rental transactions

## 🛠️ Technologies Used

- **C Programming Language**
- Structures
- File Handling
- Modular Programming
- Menu-Driven Console Interface
- Input Validation

## 📁 Project Files

The system uses text files for persistent data storage:

| File | Purpose |
|---|---|
| `vehicles.txt` | Stores vehicle records |
| `customers.txt` | Stores customer information |
| `rentals.txt` | Stores rental transactions |

*Note: Sample/initial data files are included in the repository for demonstration purposes.*

## 🚀 How to Run

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Navigate to the project directory:

   ```bash
   cd Vehicle-Rental-Management-System
   ```

3. Compile the source code using GCC:

   ```bash
   gcc *.c -o vehicle_rental
   ```

4. Run the executable:

   ```bash
   ./vehicle_rental
   ```

**Note:** If starting with an empty database, use the Add Vehicles functionality first to initialize vehicle records. Ensure the application has permission to read and write the required text files.
